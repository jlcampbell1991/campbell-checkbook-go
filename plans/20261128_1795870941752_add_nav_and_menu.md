## 1. Objective
Create a fully‑featured navigation menu and application layout for **campbell-checkbook-go** that exactly matches the existing Scala implementation, and make the HTTP server port configurable via a `.env` file.

2. **Serve the CSS** – copy the Scala stylesheet into the Go project and serve it correctly.
3. **Configurable HTTP port** – read `PORT` from a `.env` file (fallback to `8080`).
4. **Provide a `.env.example`** showing the expected variable.
5. **Document the changes** in `task-description.md` (this file) and ensure it is ignored by git.

## 5. Code Samples and Technical Details
### main.go – relevant snippet after modifications
```go
import (
    "embed"
    "html/template"
    "log"
    "net/http"
    "os"
    "path/filepath"

    "github.com/go-chi/chi/v5"
    "github.com/go-chi/chi/v5/middleware"
    "github.com/jlcampbell1991/campbell-checkbook-go/internal/config"
)

func main() {
    // Parse all layout templates
    tmpl, err := template.ParseFS(templateFS, "views/layouts/*.tmpl", "views/layouts/*.html")
    if err != nil {
        log.Fatalf("failed to parse templates: %v", err)
    }
    // Load environment variables from .env (if present)
    config.Load()

    r := chi.NewRouter()
    r.Use(middleware.Logger)
    r.Use(middleware.Recoverer)

    // Serve static assets
    staticDir := http.Dir(filepath.Join("static"))
    r.Handle("/stylesheets/*", http.StripPrefix("/stylesheets/", http.FileServer(staticDir)))
    r.Handle("/javascripts/*", http.StripPrefix("/javascripts/", http.FileServer(staticDir)))

    // Home page handler (unchanged)
    r.Get("/", func(w http.ResponseWriter, r *http.Request) {
        data := struct {
            Title string
            Body  template.HTML
        }{
            Title: "Home",
            Body:  template.HTML("<p>Welcome to Campbell Checkbook.</p>"),
        }
        if err := tmpl.ExecuteTemplate(w, "application.tmpl", data); err != nil {
            http.Error(w, err.Error(), http.StatusInternalServerError)
        }
    })

    // Configurable port
    port := os.Getenv("PORT")
    if port == "" {
        port = "8080"
    }
    addr := ":" + port
    log.Printf("Server listening on %s", addr)
    if err := http.ListenAndServe(addr, r); err != nil {
        log.Fatalf("server error: %v", err)
    }
}
```

## 6. Error Handling and Edge Cases
- **Missing `.env`** – `config.Load()` logs a message but does not abort; the server falls back to the default port.
- **Invalid `PORT` value** – the code does not validate the string; if it cannot be used by `ListenAndServe`, the call will error and the program will exit with a fatal log.
- **Static file missing** – if `application.css` is absent, the browser will load the page without styling; this is a visible failure and should be caught during manual verification.
- **Template parsing errors** – already cause a fatal log on startup.
